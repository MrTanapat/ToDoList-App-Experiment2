# 📝 My To-Do List App

โปรเจกต์นี้คือแอปพลิเคชัน To-Do List ที่พัฒนาด้วย React และ Vite โดยใช้ Container Pattern และ React Context API สำหรับการจัดการสถานะ (state)
- **Live Demo:** [Weather App](https://mrtanapat.github.io/Experiment2/)
- **Document** [DOC]()

## ✨ Features

* **การจัดการรายการ**: เพิ่ม, ลบ, แก้ไข และทำเครื่องหมายรายการที่เสร็จสมบูรณ์แล้ว
* **การจัดการสถานะ**: ใช้ React Context API เพื่อให้ components ต่าง ๆ สามารถเข้าถึงและจัดการข้อมูลรายการได้โดยไม่ต้องส่ง props
* **สถาปัตยกรรม**: ออกแบบโดยใช้ Container Pattern เพื่อแยกส่วน logic และ UI ออกจากกันอย่างชัดเจน
